# 💰 Finance App (Finans Uygulaması)

Basit ve kullanışlı bir masaüstü finans takip uygulaması.  
Gelir ve giderlerinizi ekleyebilir, kategorilere ayırabilir ve grafiklerle analiz edebilirsiniz.

---

## ✨ Özellikler
- 💵 Gelir ekleme
- 💸 Gider ekleme
- 📊 Grafiklerle analiz (Gelir / Gider / Aylık)
- 📂 Veri kaydetme ve yükleme
- 🧾 Kategori bazlı listeleme
- 📅 Tarih bazlı kayıt tutma

---

## 🛠️ Kullanılan Teknolojiler
- Python
- Tkinter (GUI)
- Matplotlib (grafikler için)
